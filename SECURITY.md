# Security Policy

## Supported versions

Only the latest version of [`booksy-biz-mcp`](https://www.npmjs.com/package/booksy-biz-mcp) on npm is supported.

## Reporting a vulnerability

Report privately through GitHub: open the
[Security tab](https://github.com/PiotrZapolski/booksy-mcp/security) of this repository and use
**Report a vulnerability** (GitHub Security Advisories). Please do not open a public issue.

Include the version, the steps to reproduce and the impact. Do not send real session tokens or client data.

## Scope

- the MCP server,
- the Chrome extension,
- the handling of the logged-in session in the browser tab.
